code-citation-lint

Lint and validate CodeMeta (codemeta.json) and Citation File Format (CITATION.cff) documents — entirely in your browser, no data leaves your machine (except when fetching by URL).

Drop a codemeta.json or CITATION.cff file here, or choose one:

GitHub repository URLs are expanded to their codemeta.json and CITATION.cff on the default branch. Note: servers without permissive CORS headers will fail in-browser.
